# 쿠버네티스 배포 연습

서버에 jar 를 올리고 `systemctl restart` 하던 방식만 해 본 개발자가, 쿠버네티스에 서비스를 **직접 배포하고 · 확인하고 · 고장을 고치고 · 되돌리는** 것까지 한 시간 안에 해 보는 연습입니다.

순서와 명령은 받으신 「서비스배포가이드(개발자용)」 **7장**과 같습니다.

> 오른쪽 터미널에서 연습장을 준비하고 있습니다 (**3~5분**).
> 터미널에 **"연습장 준비 완료"** 가 보이면 아래 **START** 를 누르세요.

### 연습장 = 작은 운영 클러스터

| 실제 운영 | 연습장 |
|---|---|
| 관리망 PC 에서 `ssh root@<k8s-m1>` | 지금 이 터미널 (controlplane) |
| 업무 서버 w1 · w2 (업무 서버 라벨) | node01 (라벨 `lab.io/role=app`) |
| 이미지 창고 infra01 `:5000` | 이 서버의 `:5000` (이름 infra01) |
| 인터넷 PC (빌드) | 이 서버의 docker |
| 대표 도메인 · 입구 가상 주소 | `ai.lab.example` → 이 서버의 443 |
| 공통 DB `db-general-rw.data-db.svc.cluster.local:5432` | **같은 주소** |
| 이미지 이름 `docker.io/<기관>/<이름>` | `docker.io/lab/<이름>` |

### 이렇게 쓰세요
- 회색 명령 상자를 **누르면 터미널에서 바로 실행**됩니다.
- 단계 끝의 **CHECK** 를 누르면 제대로 했는지 확인해 줍니다.
- 무료로 열면 **1시간** 뒤 연습장이 사라집니다. 다시 열면 처음부터 할 수 있습니다.
- 새 터미널 창을 열었다면 단계 맨 위 명령부터 다시 누르세요 (태그 값을 다시 읽음).
